## 📖 Descripción
Este proyecto es un clon de la interfaz de **Disney+**, construido con **React.js** y consumiendo una API de películas. El objetivo principal es practicar desarrollo frontend con consumo de datos dinámicos y diseño responsive estilo Disney+.

## 🛠️ Tech Stack
- ⚛️ **React.js** (create-react-app o Next.js)
- 🎨 **CSS / Tailwind CSS / Styled Components** según tu implementación
- 🌐 **API** (puede ser [TMDB API](https://www.themoviedb.org) o tu mock local)
- 🚀 **Netlify / Vercel** para deploy

---

## ⚙️ Instalación

```bash
git clone https://github.com/juanjosbg/-Disneyplus-App.git
cd -Disneyplus-App
npm install
npm run dev # o npm start
```

## 📂 Estructura del Proyecto
src/
 ├── components/    # Tarjeta de película, lista de películas, navbar...
 ├── pages/         # Páginas principales (Home, MovieDetail...)
 ├── services/      # Lógica del consumo de API
 ├── assets/        # Imágenes, logos, capturas
 └── styles/        # Estilos globales y utilidades

## Características
- Consumo dinámico de datos desde una API externa (TMDB o similar).
- UI responsiva con diseño tipo Disney+.
- Navegación fluida entre home y detalle de película.
- Buenas prácticas: componentes limpios, funciones reutilizables, estilizado modular.
